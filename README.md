# Servier drugs in clinicals trials and pubmed

## Description

This project implements a Python data processing pipeline designed to clean, transform, and analyze mentions of drugs found in scientific publications and clinical trials. The project is organized around several Python scripts, detailed in the sections below.

The main steps of the project include:

1. **Data clean** :
Apply a series of processing steps to clean and standardize the data:

    **1.1** The input files contain dates in various formats, so a standard format is applied to ensure consistent handling.

    **1.2** Handle common encoding problems, such as strings like "\xc3\x28".

    **1.3** Remove unnecessary whitespaces throughout the data.

2. **Data pipeline** :
Build a graph connecting each drug to its mentions across different journals, including the date and type of publication.
3. **Ad-Hoc Processing** :
From the JSON output generated by the data pipeline:

**•** Extract the journal that mentions the highest number of distinct drugs.

**•** For a given drug, find all other drugs mentioned in the same journals.

## SQL Section


**•** **Part 1 – Total Sales per Date**


SELECT date, SUM(prod_price*prod_qty) AS total

FROM TRANSACTIONS

WHERE date BETWEEN '2019-01-01' AND '2019-12-31'

GROUP BY date

ORDER BY date ASC

**•** **Part 2 – Sales by Product Type per Client**


SELECT

  tr.client_id,

  SUM(CASE WHEN pn.product_type = 'MEUBLE' THEN tr.prod_price * tr.prod_qty ELSE 0 END) AS ventes_meuble,

  SUM(CASE WHEN pn.product_type = 'DECO' THEN tr.prod_price * tr.prod_qty ELSE 0 END) AS ventes_deco

FROM
  TRANSACTIONS tr
WHERE
    date BETWEEN '2019/01/01' AND '2019/12/31'

JOIN
  PRODUCT_NOMENCLATURE pn
ON
  t.prod_id = pn.product_id
GROUP BY
  t.client_id
